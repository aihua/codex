# 阿里巴巴前端规约之 Node.js 开发规约

alibaba/f2e-spec《Node.js 开发规约》（MPL-2.0）全量收录。

## 何时使用

编写或评审 Node.js 服务端代码：版本选择、编码风格、安全规约（注入防护、敏感信息）、最佳实践。

## 规约等级图例

- 强制：必须遵循，评审中映射为 P0。
- 推荐：强烈建议，评审中映射为 P1。
- 参考：视具体情况选择，评审中映射为 P2。

规则编号沿用源文档节号（如 1.1、2.1）。

## 使用方式

1. 编码前：按当前任务读取对应 references 文件全文，再动手。
2. 编码中：拿不准时回到速查索引定位规则编号，再读对应原文（含说明与正反例）。
3. 引用规则时给出编号（如 2.1（防止 SQL 注入，见安全规约）），便于团队溯源与评审对齐。
4. 评审场景请改用 ali-review-nodejs，它按本技能的规则全文逐条走查并输出带严重级的违规清单。
