# 阿里巴巴前端规约之文档通用规约

alibaba/f2e-spec《文档通用规约》（MPL-2.0）全量收录，含附录术语表。

## 何时使用

撰写或修订中文技术文档、README、注释性文本：空格、标点符号、全角半角、专有名词大小写。

## 规约等级图例

- 强制：必须遵循，评审中映射为 P0。
- 推荐：强烈建议，评审中映射为 P1。
- 参考：视具体情况选择，评审中映射为 P2。

规则编号沿用源文档节号（如 1.1 中英文之间增加空格）。

## 使用方式

1. 编码前：按当前任务读取对应 references 文件全文，再动手。
2. 编码中：拿不准时回到速查索引定位规则编号，再读对应原文（含说明与正反例）。
3. 引用规则时给出编号（如 1.1（中英文之间需要增加空格）），便于团队溯源与评审对齐。
4. 评审场景请改用 ali-review-markdown，它按本技能的规则全文逐条走查并输出带严重级的违规清单。
