# 阿里巴巴前端规约之 JavaScript 编码规约

alibaba/f2e-spec《JavaScript 编码规约》（MPL-2.0）全量收录。面向 ES6+，另含「关于 ES5」章节供仍在使用 ES5 的开发者查阅。

## 何时使用

编写或评审 JavaScript / ES6+ 代码：编码风格（缩进、分号、逗号、空格、空行、行宽）、语言特性（变量声明、原始类型、数组、对象、函数、类、模块、操作符、控制语句）、注释与命名时。

## 规约等级图例

- 强制：必须遵循，评审中映射为 P0。
- 推荐：强烈建议，评审中映射为 P1。
- 参考：视具体情况选择，评审中映射为 P2。

规则编号沿用源文档节号（如 1.1 缩进、2.3 数组），规则条目为 x.y.z 编号（如 1.2.1）。

## 使用方式

1. 编码前：按当前任务读取对应 references 文件全文，再动手。
2. 编码中：拿不准时回到速查索引定位规则编号，再读对应原文（含说明与正反例）。
3. 引用规则时给出编号（如 1.2.1（使用分号）），便于团队溯源与评审对齐。
4. 评审场景请改用 ali-review-javascript，它按本技能的规则全文逐条走查并输出带严重级的违规清单。
