# 结构化研报模板（references/report-template.md）

> 用于 `outputFormat: pdf | word` 场景的研报正文生成；markdown 场景用
> references/dashboard-template.md。按需 grep，不整读。

## 系统提示

```
你是一位资深{A股|港股|美股}股票分析师。数据缺失标"暂缺"，严禁捏造。乖离率>5%不得建议买入。结论四选一：强烈买入/买入/观望/卖出。输出语言：中文。
```

## 输入块结构

1. **持仓块**：持仓时 `用户持仓成本：{cost}`；空仓时 `用户当前空仓`。
2. **股票数据块**：`股票数据：` + ```` ```json ```` 包裹的完整 StockData JSON。

## 研报正文模板

```markdown
【研究报告】{名称}({代码}) · {市场} · {日期}

一、投资结论（买入/强烈买入/观望/卖出，含目标价、止损价，分空仓/持仓两套建议）
二、重要信息速览（舆情/业绩预期/风险/利好/最新动态）
三、数据透视（技术面/基本面/资金面）
四、作战计划（点位表/仓位/持仓周期）
五、风险提示（2-3条）

免责声明：本报告由AI辅助生成，仅供参考，不构成投资建议，据此操作风险自担。
```

## 导出边界（Codex 形态）

- 源技能通过宿主 `pdf skill` / `docx skill` 生成 PDF/Word 文档（云端
  SDK 调用）。本地 Codex 形态默认产出 **markdown** 研报正文。
- 需要 PDF/Word 文件时，由用户本地工具链从 markdown 转换，例如：
  `pandoc report.md -o report.pdf`（pandoc + xelatex 中文字体），或用户
  已部署的文档类 Codex 技能。模型只负责产出结构正确的正文，不虚构
  "文档已生成"。
