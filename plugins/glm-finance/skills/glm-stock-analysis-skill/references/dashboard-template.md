# 决策仪表盘模板（references/dashboard-template.md）

> 由模型按本模板产出每只股票的七段式决策仪表盘；确定性部分（评分/自选股/
> 报告组装）走 `scripts/stockcli.py`。本文档按需 grep，不整读。

## 系统提示（System Prompt）

```
你是一位资深{A股|港股|美股}股票分析师。数据缺失标"暂缺"，严禁捏造。乖离率>5%不得建议买入。结论四选一：强烈买入/买入/观望/卖出。输出语言：中文。
```

## 输入块结构

把以下三块按序拼装后作为 user prompt：

1. **数据预警块**（有 warnings 时）：

```
⚠️ 数据预警（必须在报告中体现）：
- {warning 1}
- {warning 2}
```

2. **持仓块**（按用户提供的三种形态）：

| 形态 | 拼装文本 |
|---|---|
| 持仓中 | `用户持仓：持仓中，成本价 {cost} 元{，{shares} 股}。请给出盈亏分析和针对性建议。` |
| 空仓 | `用户持仓：当前空仓。` |
| 未提供 | `用户持仓：未提供（请同时给出空仓者和持仓者两套建议）。` |

3. **股票数据块**：`股票数据：` + ```` ```json ```` 包裹的完整 StockData JSON
   （schema 见 references/data-schemas.md）。

## 仪表盘正文模板（严格按结构，不增删章节）

```markdown
---

## 决策仪表盘 · {名称}({代码}) · {市场}

---

### 📰 重要信息速览
**💭 舆情情绪：** 一句话描述
**📊 业绩预期：** 结合 PE/ROE/行业简述，数据缺失标"暂缺"
**🚨 风险警报：**
- 风险1（技术面或宏观）
- 风险2（基本面或行业）
**✨ 利好催化：**
- 利好1（技术面）
- 利好2（基本面或行业）
**📢 最新动态：** 结合行业背景，补充1条关键信息

---

### 📌 核心结论
**[emoji] 结论：强烈买入 / 买入 / 观望 / 卖出**（四选一，乖离率>5%不得为买入）
**💬 一句话决策：** 核心逻辑
**⏰ 时效性：** 立即行动 / 今日内 / 不急

（根据持仓状态输出）
- **🆕 空仓者：** 是否进场、建仓点位、仓位比例
- **💼 持仓者：** 持有/加仓/减仓/止损建议{，含成本盈亏分析}

---

### 📈 当日行情
列出：收盘价、昨收、开盘、最高、最低、涨跌幅、涨跌额、振幅、成交量、成交额（缺失标"暂缺"）

---

### 📊 数据透视

**技术面：**
表格（指标 | 数值 | 解读）：MA5、MA10、MA20、乖离率(BIAS20)、RSI（如有）、支撑位、压力位
结论：均线状态 + 趋势强度（xx/100）

**基本面（注明报告期）：**
表格（指标 | 数值 | 行业对比）：ROE、毛利率、净利率、资产负债率、PE、PB
数据缺失标"暂缺"，不得捏造

**资金面：**（A股/港股适用，美股可略）
- 主力净流入：金额（占比%），一句话解读
- 筹码：获利比例 | 平均成本 | 集中度

---

### 🎯 作战计划

| 点位类型 | 价格 | 说明 |
|---------|------|------|
| 🎯 理想买入 | xxx | |
| 🔵 次优买入 | xxx | |
| 🛑 止损位   | xxx | |
| 🎊 目标位   | xxx | |

**💰 仓位建议：** x成
**建仓策略：** 分批策略
**风控策略：** 止损纪律

---

### ✅ 检查清单
- ✅/⚠️/❌ 均线状态
- ✅/⚠️/❌ 乖离率安全（<5%）
- ✅/⚠️/❌ 量能配合
- ✅/⚠️/❌ 估值合理
- ✅/⚠️/❌ 资金流向
- ✅/⚠️/❌ 筹码健康

**综合结论：** 一句话总结当前状态和建议。

---
*以上分析仅供参考，不构成投资建议，据此操作风险自担。*
```

## 结论提取约定

仪表盘生成后，结论四选一的抽取由 `stockcli.py verdict` 确定性完成，匹配
顺序：`结论：X` → `核心结论：X` → `**X**`；无匹配默认「观望」。模型不要
自行另造结论词。

## K线图分析（图像输入）

用户上传 K 线图时：若部署模型支持图像输入（多模态），按以下提纲直接分析
（系统提示：`你是技术分析专家，擅长K线形态识别。请用中文回答。`）：

```
这是 {stockCode} 的K线图，请分析：
1. 当前K线形态
2. 趋势方向
3. 关键支撑位和压力位
4. 成交量配合
5. 短期操作建议
```

若部署模型**不支持**图像输入（纯文本模型），先请用户描述：K线组合形态
（如十字星/大阳线/三连阴）、均线排列、量能变化、图中标注的价位——再按
同一提纲完成分析。严禁在没看到图/描述时编造形态。
