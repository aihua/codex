## USER.md 总体结构

```markdown
# 用户档案

## 1. 基础信息
（姓名/称呼、时区、可用学习时段、每日学习时长偏好、学习兴趣）

## 2. 学习项目
（进行中/已完成/已暂停的项目块，见下）

## 3. 薄弱知识点
（错误次数 ≥ 3 的知识点登记表；只增不减，不解除）

## 4. 备注
（glm-web 插件技能自定义路径、用户偏好约定等运维备注）
```

## 项目块结构（"学习项目"分区内，每项目一块）

```markdown

- 状态：进行中          # 进行中 / 已完成 / 已暂停
- project_id: P1        # 自编递增：P1/P2/P3…
- 开始日期: 2026-11-21
- 计划确认: 已确认      # 待确认 / 已确认
- 提醒设置: 已完成      # 未完成 / 已完成
- 截止日期: 2026-12-05  # 可选，用户给了才写

- 计划总天数: 14

#### 知识点叶子列表

```

### 字段语义与写入者

| 字段 | 语义 | 谁写、何时 |
|---|---|---|
| `状态` | 项目生命周期 | 项目全叶子 [x] → 已完成（晚间复盘）；用户停学 → 已暂停 |
| `project_id` | 项目本地 ID | 步骤2 生成时自编（P1/P2/P3 递增） |
| `计划确认` | DAY 表是否已被用户确认 | 步骤3 展示表格 → 待确认；用户说可以 → 已确认 |
| `提醒设置` | 定时器是否已装 | 问完时间装好定时器 → 已完成（手动形态也算） |
| `学习资料` | 资料来源（链接或本地路径） | 步骤1/1.5 写入 |
| `[ ]`/`[x]` | 是否练过（与练过字段**同步**） | 晚间复盘：用户确认练过 → [x] |
| `knowledge_id` | 知识点本地 ID（P1-K03 = 项目1-第3知识点） | 步骤2 写叶子时编号 |
| `DAY` | 排期天数编号 | 步骤3 用户确认后从"未分配"改 N；晚间复盘可调整 |
| `学完` | 用户口头确认学完（当天交互写） | 白天用户说学完 → 是 |
| `练过` | 用户确认做过练习 | 晚间复盘 → 是（与 [x] 同步） |
| `答对` | 累计答题战绩 答对数/答题数 | 晚间复盘按口述与当日对答案记录累加 |

### 状态机铁则

- **白天只动 `学完`**；`练过`/`[x]`/`答对`/`DAY` 调整/薄弱知识点全部
  晚间复盘独占（SKILL.md 模块3 关键原则）
- `[x]` 与 `练对: 是` 必须同步（只改一个 = bug）
- `答对` 累加语义：新战绩叠加旧值（4/8 → 今晚又对 3/5 → 7/13），
  **不覆盖**
- 薄弱知识点只增不减，不解除

## memory/ 日记格式（事件流水，严禁覆盖）

`memory/YYYY-MM-DD.md`（每天一份，没有就创建，**追加不覆盖**）：

```markdown
## [2026-11-21] 学习记录

- [09:41] 项目生成：LLM 入门（26 个知识点，来源 Attention 详解）
- [14:23] 学完 2 个知识点（P1-K01、P1-K02）
- [15:02] 全天学完，生成练习 quiz/quiz-2026-11-21.md（10 题）
- [22:05] 晚间复盘：口述战绩 7/10，打勾 3 个叶子，DAY 6→5 提前
- [22:05] 解锁成就：【七日不断更】
```

> 只记**事件**（什么时候发生了什么），知识点明细 USER.md 已有，不重复。

## quiz/ 练习文件格式

`quiz/quiz-YYYY-MM-DD.md`（当日一份；用户单点练习时
`quiz/quiz-YYYY-MM-DD-<knowledge_id>.md`）：

```markdown
# 今日练习 · 2026-11-21

覆盖知识点：P1-K01 Transformer 整体架构 · P1-K02 注意力机制 QKV

## 选择题

1. Transformer 中 self-attention 的输入是？
   A. 词嵌入序列  B. 位置编码  C. 两者拼接  D. LSTM 状态
   （答案：C —— 资料 §2 第 3 段）

## 简答题

3. 用一句话说清 QKV 三个矩阵各自的作用。
   （要点：Q 查询 × K 键匹配 → V 值加权求和）

---
## 用户作答记录（对答案后填）

- 选择题：3/3 对
- 简答题：2 题中 1
- 合计：4/5
```

> 题目必须来自当日学习资料内容；答案标注资料出处段落。用户答完后当场
> 对答案，此文件即战绩凭证，晚间复盘据此 + 用户口述合并结算。

## report/ 报告文件格式（主动查询长报告时落盘）

`report-<范围>.md`（如 `report-2026-W47.md`、`report-LLM入门-总结.md`）：

按 references/reporting.md 的①②③④结构写全，文件头加一行：

```markdown
> 生成时间：2026-11-21 22:10 · 数据源：USER.md（只读快照）
```
